# Round 506 — Booking Board: rows missing / appearing / vanishing under brand tabs
Report: The Khang Show EP 42/41 ("INT Media Support"): TikTok Channel / Community rows appeared then vanished, VPOP tabs empty, BOLERO tab showed rows that don't belong, counts differed from All.
Causes found:
1. loadPage()/refreshCounts() had no stale-response guard — each filter click fires several RPC loads (subFilter -> tiktokBrandFilter reset -> columns change); a slower older response overwrote the newer one ("shows then gone"). Fix: latest-request-wins ref in app/booking/page.js.
2. booking_brand_has_any_target() (Social/Community/TikTok Channel) checked only "any blank-brand line in the category", so any release with a Community/TikTok line passed EVERY brand tab; releases built the older per-brand-line way (EP 42/41) matched none. Fix SQL: sql/pending/fix-round506-booking-board-brand-target-filter.sql — visible under brand B only if brand_column_quantities has a "B::" key, or an older per-brand line with brand B exists.
Known limit: EP 42/41 per-brand lines carry no per-column split (no brand_column_quantities), so their row now appears under PAGE VPOP / TIKTOK VPOP but column cells stay "—" until the package is rebuilt/re-summarized. Package popup still shows the totals.
Needs the SQL run; no Round 418 resync.
