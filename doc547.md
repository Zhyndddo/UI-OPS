# Round 547 — Phái Sinh / Kho Nhạc import accepts any spreadsheet

Request: "can we make it be able to import anything?"

## What changed
- **Columns are matched by header name, in any order.** "Tên bài hát", "ten bai", "Song", "Track name", "Title" all mean the song title; same for Artist/Nghệ sĩ, Ngày phát hành/Release date, UPC, ISRC, Ghi chú/Note, the three Tác quyền Q1/Q2/Q3 columns, etc. Case, accents and punctuation are ignored. Unknown columns are ignored. A title row above the header is fine (header is searched in the first 10 non-blank rows).
- **No recognisable header** → the old fixed template order is used, exactly as before (verified identical output on 300 random rows, with and without the template header, for file rows and for paste).
- **Preview step after choosing a file** (app/tickets/phai-sinh/new and the batch page's "+ Add Via Paste"): each column has a dropdown, so any wrong or unmatched column can be re-pointed; shows the first 3 data rows and "N songs will be imported, M skipped (no song title)". A sheet picker appears for workbooks with several sheets (first sheet with data is chosen). One column per field (choosing a field again moves it).
- **More file types**: .xlsx, .xls, .ods, .csv, .tsv, .txt. Text files are read as UTF-8 (BOM stripped) and kept as exact text, so Vietnamese letters survive and "2/6/2025" stays day-first (2 June) instead of being re-read as a US date.
- **Paste** is header-aware too (first line a header → matched by name; otherwise template order).
- Round 438 still holds: the create form can continue with zero songs ("Continue without songs"). Adding to an existing batch needs at least one song (allowEmpty={false}).
- File is no longer imported the moment it is chosen; it imports when you press the Import button.
