- Visible ONLY to accounts in lib/chatProto.js (CHAT_PROTO_EMAILS, currently an.thien@vieent.vn — the Cosmic account; change that one line to move it). Everyone else: renders nothing, loads nothing. (App has no RLS, so this is an app-side gate, fine for a test.)

Open two tabs of the same account to see live delivery. Truth source is still Supabase dashboard: note Usage → Egress and Realtime (messages, peak connections) before and after your test.

Idempotent. Tested twice on scratch Postgres (updated_at touch trigger works). UNDO: drop table if exists chatx_messages, chatx_channels cascade;
- Not in the prototype (by design): unread badges, notifications, DMs, threads, reactions, search, files, private channels.
