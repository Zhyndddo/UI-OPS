# Round 504 — Cost MKT self-heals missing non-DID products
Root cause of Chim Sáo Ngày Xưa not counting: ticket had a hand-typed nonDidCode but non_did_products was empty; Cost MKT builds non-DID rows only from that table. Fix: on load, Cost MKT creates a product for any live Booking Không Trong Package ticket whose nonDidCode has no product row (name from productName/tenBai, artist from nonDidArtist, label from ticket) and shows it immediately. Unique code index makes it safe. No SQL required (insert-chim-sao-nondid-product.sql now optional). Tickets with neither DID nor code still show the workstation warning and are not counted.
