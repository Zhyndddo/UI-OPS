# Round 529 — Booking Board INT: hide empty "Chỉ Phát Hành" releases

Finding (2026-10-20 backup): 237 releases are Chỉ Phát Hành; only 6 have any booking activity (4 with entries, 4 with a package line quantity > 0, overlapping), 231 have nothing. Rounds 378/379 admitted ALL of them to the INT tab and made them always pass the target filter, so the INT tab shows rows of dashes.

Fix (SQL only, no app change): new `booking_cph_has_activity(release)` = has a media_booking_entries row OR a package line with quantity > 0. booking_board_page() and booking_has_target() now let a Chỉ Phát Hành release in only when that is true (also in the INT stat-card count). Releases with activity show exactly as before; empty ones vanish and reappear by themselves once something is added. Nothing deleted.
