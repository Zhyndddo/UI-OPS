# Round 560 — Task Table cache + health-check SQL

## Task Table faster
Before: every visit ran ~6 query groups (profiles, all recent releases, tickets per type, workstation assignments, booking-board RPC) and showed a skeleton until all finished.
Now:
- Loaders moved unchanged to lib/taskTableData.js (page.js imports them) — same numbers, same logic.
- In-memory cache for the tab. Opening the page shows the last result instantly with a small "updating…" next to the title, then swaps in fresh numbers.
- A refresh younger than 60 s is reused (no extra reads when hopping back and forth).
- Hover / focus / touch on the sidebar "Task Table" link starts the load early (loaded on demand, no weight on other pages).
- People who opened the Task Table in the last 7 days get it warmed ~6 s after the app opens. People who never use it cost nothing.
- Not cached across a full page reload (first load after reload is as before).
Egress: roughly the same reads as before per visit; the repeat visits within a minute now cost zero. The warm-up moves the cost earlier, it doesn't add visits.
