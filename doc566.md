# Round 566 — Halloween "draw the pumpkin face" teaser

## What it does
Event days: 30 Oct – 1 Nov 2026 (Vietnam date, enforced in the API).
A rare glowing 🎃/🦇 falls -> click -> big bat flies across -> click -> hidden panel fades in with a blank pumpkin.
User draws eyes (2, upper half) + mouth (1, lower half). "Gửi bí ngô" -> server checks.
First valid drawing of the day wins 1 Jollibee combo (one prize per day for the whole team). Max 5 tries/person/day.
Every drawing is stored in `halloween_drawings` (png base64) AND uploaded to Google Drive when configured.
Owner (an.thien@vieent.vn) = practice mode: any date, never takes the day's prize, can test everything.
Winner -> notification to owner ("🍔 <name> won today's Jollibee combo").

## Run order
1. Run `sql/pending/add-round566-halloween-face.sql` in Supabase SQL editor.
2. Google Drive webhook (below), then add Vercel env vars:
   - `HALLOWEEN_DRIVE_WEBHOOK_URL` = the Web app URL
   - `HALLOWEEN_DRIVE_SECRET` = same secret as in the script
3. Unzip into repo, push, redeploy (env vars need a redeploy).
Drive is optional: without env vars everything works, drawings stay in the DB table.

## Google Apps Script (script.google.com > New project)
```js
const SECRET = 'CHANGE_ME_LONG_RANDOM';
const FOLDER_ID = 'DRIVE_FOLDER_ID'; // from the folder URL .../folders/<ID>
function doPost(e) {
  try {
    const d = JSON.parse(e.postData.contents);
    if (d.secret !== SECRET) return out({ ok: false, error: 'forbidden' });
    const blob = Utilities.newBlob(Utilities.base64Decode(d.dataBase64), d.mimeType || 'image/png', d.filename);
    const f = DriveApp.getFolderById(FOLDER_ID).createFile(blob);
    return out({ ok: true, url: f.getUrl(), id: f.getId() });
  } catch (err) { return out({ ok: false, error: String(err) }); }
}
function out(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
```
Deploy > New deployment > Web app > Execute as: Me > Who has access: Anyone > Deploy > authorize > copy URL.

## Test (as owner)
Open the app any day -> sticker appears after ~4 s -> click -> bat -> click -> draw 2 eyes + mouth -> send.
Expect "practice" result; check `halloween_drawings` (practice=true) and the Drive folder.
Non-owner test is only possible 30 Oct–1 Nov.
