## 1. Per-month numbers (Cost Marketing, rows with Is_installment on)
- No. Booking Post, No. Support Post, Cost Dự Kiến now flip with the month (◀/▶) like Cost Thực Chạy already did. A month starts blank.
- Numbers typed BEFORE months existed stay as an "all months" BASE: small "base" field under each of the three cells. All view = base + every month; a picked month = that month only.
- Cost Thực Chạy keeps its old rule (its flat value is ignored once months exist) so no existing total moves.
- Summed: frozen snapshots (Booking / Support / Total Post, "tổng số post") follow the month filter. Top cards only ever used Cost Thực Chạy / Vieent hỗ trợ / Artist trả / Sup cashback, unchanged.
- Row's "Total Post" column is still the live count from the booking data (unchanged). Export / Import still read and write the flat (base) numbers.
- A row in Is_installment mode with no month yet shows the normal single cells until the first month is added.

## 2. Older products in Booking Không Trong Package
The DID field only searched the newest 300 releases (the 🔍 picker the newest 200) in the browser, so older products never matched. Both now also search the database as you type (title, artist or DID, 2+ characters). lib/releaseSearch.js (new), lib/RelatedDidField.js, lib/ReleasePicker.js.

## 3. Missing YouTube Ads rows
Round 507 limited the YouTube Ads list to songs flagged "Có Trong Net YouTube", on both sides, and non-DID products can never carry the flag. That gate is removed. Rows still need a ticket whose Brand is exactly "YouTube Ads" and Hạng Mục exactly "Thruplay (Views)", not cancelled/refunded, with a quantity; if one is still missing after this, check those two fields on that ticket.
