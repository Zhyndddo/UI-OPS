# Round 568 — Drive big-file upload: PROOF OF CONCEPT (owner only)

No SQL. No new env vars (reuses HALLOWEEN_DRIVE_WEBHOOK_URL / HALLOWEEN_DRIVE_SECRET; DRIVE_WEBHOOK_URL / DRIVE_SECRET also accepted).

## Steps
1. Apps Script: paste `drive-webhook-v2.gs` over your script, KEEP your own SECRET + FOLDER_ID lines. Deploy > Manage deployments > pencil > Version: New version > Deploy.
   Google asks for one extra permission ("connect to an external service"): Review permissions > your account > Advanced > continue > Allow. (The URL stays the same.)
2. Push this zip (app/api/chat-upload/route.js, app/api/chat-upload/chunk/route.js, app/upload-test/page.js, lib/shortLinks.js). Wait for the Vercel deploy.
3. Sign in as an.thien@vieent.vn, open /upload-test (not in the menu). Pick a ~40 MB file. Mode "direct" first, press Upload.
   - Works: progress goes to 100%, "Verified and shared with the VIEENT domain", an "Open in Drive" link and a preview.
   - If it says blocked by the browser (CORS): choose "via our server" and upload again. Tell me which mode worked.
4. In Drive check: <your folder>/chat-uploads/2026-10/<timestamp>_<name>. Open the link in a private window: it must ask for a Google sign-in (domain only).
5. Optional: try an audio file, then the preview iframe should play it.

## What each failure means
- "Drive webhook not configured": env vars missing / not redeployed.
- "forbidden": secret mismatch or the script's New version not deployed.
- "init failed 401/403": the script needs the new permission (step 1) or the Drive API is blocked by your Google admin.
- "could not share with the domain": the script owner account is not a VIEENT Workspace account, or the admin blocks domain sharing. Tell me the exact text.
- "file not found in Drive" after a finished upload: browser upload landed but the lookup failed; send me the log.
- "size mismatch": the upload was cut short; retry.

## Design (what comes after the test passes)
Browser asks our server (auth, 100 MB cap, blocked types: exe msi bat cmd scr com jar vbs ps1 dmg apk app pkg) -> script opens a Drive resumable upload slot in chat-uploads/YYYY-MM -> browser sends the file straight to Google in 8 MB pieces (fallback: 4 MB pieces through /api/chat-upload/chunk) -> server asks the script to verify size, share with the VIEENT domain (link) and return the link -> chat message row with the file card. Zero Supabase/Vercel egress for the file itself. Monthly folders make the tidy-up one delete per month.
