# Round 555 — Chat mentions: bubble badge + sound, no more bell rows

Builds on 552–554.

## Run order
1. Run `sql/pending/add-round555-chat-mentions.sql` (idempotent).
   - Adds `chatx_messages.mention_ids uuid[]` + a small GIN index, backfilled from stored tags.
   - Deletes the old `chat_mention` / `chat_help` rows from `notifications`.
2. VERIFY at the bottom: column + index (2 rows), and `leftover_chat_notifications` = 0.
3. Push `lib/ChatDock.js`, `lib/chatGuides.js`, `lib/patchNotes.js`.

## What changed
1. **No bell rows, no toast** for chat mentions. Chat now writes zero rows to `notifications`.
2. **Red number on the chat bubble** = messages in the last 7 days that tag you and you haven't looked at. Per-channel counts show in the channel list. Opening a channel marks its mentions seen (remembered in this browser only).
3. **Tagging rule** (@ # $): after the symbol + **1 letter** a list of real options appears; click, or ↑ ↓ then Enter/Tab; Esc closes; "No match" is shown when nothing fits. Only a picked option becomes a real tag.
4. **Sound** (soft two-note pop) when a new message tags you; 🔔/🔕 in the chat header mutes it (saved in this browser). Not played for your own messages or on first load. Browsers only allow sound after you've clicked somewhere on the page once.
5. `@helper` with no matching guide now replies with a message that tags Zhyn (so it lands on Zhyn's badge) — no bell row.

## Database weight
- New rows: none in `notifications`. One extra column (16 bytes/message) + GIN index on a small table.
- New traffic: each signed-in browser asks "any new message tagging me?" once a minute while the tab is visible (a count-only request, ~0.3 KB), plus one small load when the app opens. ≈ 30 staff × 8 h ≈ 15k tiny requests/day ≈ 5 MB/day (≈2% of the ~200–280 MB working-day baseline). When someone is tagged, one extra read of that few rows.
- `#` with 1 letter does a prefix search (limit 6) on releases; with 2+ letters it uses the trigram indexes from Round 553. `@` and `$` are free (local).
- Nothing realtime is added while the chat is closed.
