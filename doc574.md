# Round 574 — Event check-in (register -> QR by email -> scan at the door)

Pages (public, no login, noindex):
- /register  — guest enters name, email, organisation (optional) + the EVENT CODE. Gets a personal QR on screen AND by Gmail.
- /checkin   — door staff enter the DOOR CODE, then scan guest QRs with the phone camera (or type the code). Green = welcome, amber = already checked in (shows when), red = not on the list. Shows "checked in X / Y registered".

Guest list = a Google Sheet "Event check-in" (made automatically in your Drive folder). Columns: Registered | Name | Email | Organisation | QR token | Mail | Checked in | Mails sent. Nothing is stored in the database.

Rules built in: same email registering again gets the SAME QR re-sent (max 5 emails per guest); a QR works for one check-in, the second scan says "already"; QR is a random 22-char token (EVT1.xxxx), not guessable; rate limits per visitor (in server memory); honeypot field against bots; Gmail quota is checked before sending.

SETUP (in this order):
1. Vercel env vars (no quotes): EVENT_REGISTER_CODE = code for guests, EVENT_DOOR_CODE = code for door staff. Redeploy after pushing.
2. Apps Script: paste drive-webhook-v6.gs (keep your SECRET + FOLDER_ID). Pick `authorizeAll` in the function dropdown, press Run, approve ALL permissions (Sheets, Drive, Gmail send). THEN Deploy > Manage deployments > pencil > New version. (Permission first, new version after — the order that fixed the log earlier.)
3. Push the code, open /register on a phone, register yourself, check the email arrives, open /checkin on a second phone, scan it from the first phone's screen or the email.
4. Before the event: edit lib/eventConfig.js for title/date/place/host/note (it is pre-filled from the invitation). Gmail limit: about 100 emails/day on a free Gmail, 1,500 on Google Workspace (the script account decides).

Files: app/register/{page,layout}.js, app/checkin/{page,layout}.js, app/api/event-register/route.js, app/api/event-checkin/route.js, lib/eventConfig.js, lib/qrPng.js, lib/eventRateLimit.js, lib/vendor/qrcode-generator.js (MIT), lib/vendor/jsQR.js (Apache-2.0) — libraries are copied into the repo, no npm install or package.json change; lib/shortLinks.js ("register","checkin" reserved); drive-webhook-v6.gs.
