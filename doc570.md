# Round 570 — Public Picture render (/picture)

New public page (no login, like the channel page): https://<your site>/picture
- Visitor types the shared ACCESS CODE, then the same Picture render screen (max 30 names per batch, PNG / zip download).
- Each picture is also saved to Drive (folder picture-render/invitation) via /api/picture-render-public. Nothing is written to the database.
- Not indexed by Google (noindex + robots.txt already blocks everything except the channel page).

Protection (no database, so limits live in server memory = per server instance, a brake not a vault):
- access code from Vercel env PICTURE_PUBLIC_CODE (page stays OFF with a "not switched on" message while it is missing)
- 8 wrong codes per visitor / 10 min -> locked for the rest of the window
- 40 Drive saves per visitor / 10 min, 300 total / 10 min
- PNG/JPEG only, real image bytes checked, <= 4.4 MB, known folder only; the Drive link is NOT shown to the public
